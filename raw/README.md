# Raw Notes

`raw/` は、保存依頼で受け取った議事録、長文メモ、複数 entity 混在メモの原本を置く場所です。

公開テンプレートでは、実在企業、担当者名、メールアドレス、電話番号、契約金額、単価、非公開 URL を含めないでください。実運用では、raw note は社内用 memory として扱い、顧客向け draft から直接参照しません。
